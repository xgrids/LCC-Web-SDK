# LCC-Web-SDK

[English](./README.md) | 中文

## 介绍

LCC Web SDK是其域官方提供的LCC开发套件，支持在Web端加载lcc文件，并将数据渲染出场景，支持射线检测，点云切换，环境数据切换，细节渲染等诸多常用功能。支持主流浏览器：Chrome，Firefox，Safari，Edge。

## 下载

请访问 [https://developer.xgrids.com](https://developer.xgrids.cn/#/download?page=LCC_WEB_SDK) 获取最新版本插件

## 特性

- 支持主流PC浏览器支持：Chrome, Firefox, Safari, Edge 
- 支持Three.js和Cesium.js 
- 支持基础渲染和球谐渲染分离 
- 支持实时开启和关闭球谐渲染 
- 支持环境数据加载、实时显示和隐藏 
- 支持点云和3DGS渲染切换 
- 支持射线检测，支持Mesh射线检测 
- 支持碰撞 
- 支持本地数据缓存 
- 支持全局Alpha调整 
- 支持Box和平面裁切 
- 支持对带token的meta.lcc文件链接请求校验
